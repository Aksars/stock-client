# stock-client

Клиент стратегии: маленькая программа, которая работает на компьютере пользователя, спрашивает сервер стратегии
«какие доли держать сейчас?» и исполняет ответ на **собственном брокерском счёте пользователя в T-Invest его же токеном**.

- Сервер получает от клиента только запрос с ключом доступа. Токен брокера, номер счёта, позиции и заявки **никогда не уходят на сервер**.
- От сервера приходят только итоговые доли (бумага → доля портфеля) и даты; клиент проверяет их по своим ограничениям
  (только биржевые тикеры, денежная часть только в фонде TPAY, не больше 50% портфеля в одной бумаге, не больше 30 бумаг).
- По умолчанию всё выключено: без включённого режима и без нажатия «Да, исполнить» заявки не уходят.
  Автоисполнение — отдельный переключатель, на реальном счёте включается только с вводом фразы.
- Самообновления нет: новая версия — новый файл, который пользователь скачивает сам.

Рабочая версия — **`go/`**: один файл без сторонних зависимостей (только стандартная библиотека Go), воспроизводимая сборка.
Как убедиться, что программа делает только это, — **`go/AUDIT.md`** (полный список сетевых соединений и способы проверки).

`client/` — эталонная реализация того же поведения на Python (для тестов и сравнения), `tests/` — её тесты.

**Запуск:** скачать файл для своей системы, запустить — откроется http://localhost:8240. Дальше в интерфейсе:
«Настройки» (адрес сервера, ключ сервера) → «Торговый токен T-Invest» → «Загрузить счета» и выбрать счёт →
«Проверить счёт» (ничего не отправляет) → режим «Песочница» (виртуальные деньги брокера) → при желании — реальный счёт.

Это не инвестиционная рекомендация; решения по своему счёту пользователь принимает сам.
